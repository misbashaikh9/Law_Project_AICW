# LawBridge-AI

## Overview

LawBridge-AI is an AI-powered legal assistance platform designed to help users understand legal information through natural language interactions. The platform combines Artificial Intelligence, Natural Language Processing (NLP), and full-stack web development to provide contextual legal guidance through an intuitive interface.

## Features

* AI-powered legal query assistance
* Natural Language Processing (NLP) for user queries
* User authentication and authorization
* Secure backend APIs
* MongoDB database integration
* Full-stack architecture with separate AI service
* Responsive and user-friendly interface

## Tech Stack

### Frontend

* React.js
* Vite
* JavaScript
* HTML5
* CSS3

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

### AI Service

* Python
* FastAPI
* Scikit-learn
* NLP Processing

## Project Architecture

LawBridge-AI follows a multi-service architecture:

* Frontend: User interface and interactions
* Backend: Authentication, APIs, and database operations
* AI Service: Legal query processing and AI-generated responses

## Installation

### Clone Repository

```bash
git clone <repository-url>
cd LawBridge-AI
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### AI Service Setup

```bash
cd ai-service
pip install -r requirements.txt
uvicorn main:app --reload
```
